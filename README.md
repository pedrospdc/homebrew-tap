# pedrospdc/homebrew-tap

Homebrew tap for [pedrospdc](https://github.com/pedrospdc) tools.

```sh
brew install pedrospdc/tap/container-compose
```

| Cask | Description |
|---|---|
| [`container-compose`](https://github.com/pedrospdc/apple-container-compose) | Docker Compose for Apple container |

Casks in `Casks/` are generated by GoReleaser on each release. Don't edit them by hand.
